# FAKE-LAG-3.0

Aplicación para Android desarrollada en Kotlin que implementa un túnel de red VPN local con un sistema de estabilización y retraso fraccionado de paquetes para optimizar la estabilidad en conexiones móviles.

## Características
- VPN local 100% autónoma (sin servidores externos ni modificación de archivos de juegos).
- Control de retraso dinámico mediante corrutinas de Kotlin para evitar desconexiones bruscas.
- Interfaz moderna en modo oscuro con estética azul eléctrico.
